# Runtime 版本与分支方案

## 当前状态

- 3.8：已集成，产物 `SpinePreview3.8.app`。
- 2.1.25：源码已加入 `Vendor/Spine21/`，固定提交 `142e770e5b4b42395a3a0a68ff3c8a21ba2774eb`。已集成，产物 `SpinePreview2.1.app`。

## 分支选择

| 方案 | 优点 | 代价 |
| --- | --- | --- |
| 长期独立 2.1 分支 | 初次移植可直接改现有实现；旧版本可独立冻结和发布 | 文件加载、PMA、界面、平台修复需要重复合并；两个版本容易出现行为差异 |
| main 同时维护多个 runtime | 共用界面、资源发现和平台代码；一次修复可覆盖多个应用；同一提交可生成各版本 | 需要明确适配接口、按版本选择构建依赖、隔离版本校验和资源解析 |
| 短期功能分支，完成后合回 main | 接入过程不影响 main 的可用版本，合并后共享维护 | 需要控制分支周期，并在合并前验证两个版本 |

采用 main 共用代码、各版本独立适配和独立应用的方案。未来较大的新版本接入可使用短期功能分支，验证后合回 main，不长期维护版本分支。

默认 `SPINE_VERSION=all` 同时构建两个应用，也可选择 `2.1` 或 `3.8`。应用名、Bundle ID、默认资源和许可证各自独立，每个可执行文件只链接对应 runtime。

## 当前实现

- `Sources/SpinePreview.h` 是统一适配接口，使用 Pimpl 隐藏 runtime 类型；构建时分别选择 `Sources/Runtimes/Spine21.cpp` 和 `Spine38.cpp`。
- 默认窗口逻辑尺寸为 1136×640，参考 iPhone 5s 横屏像素分辨率；新实例继承源窗口当前尺寸。
- SDL3 窗口、ImGui 界面、动画选择及播放控制共用 `Sources/main.cpp`。资源发现、Atlas 配对、手动纹理映射和隔离校验流程共用 `FileLoader.*` / `ResourceFiles.*`，按编译目标执行版本策略及 Atlas 规范化。
- 预览区左键拖动使用共用输入逻辑维护屏幕坐标偏移，传入统一 draw 接口，由两个适配层在几何投影时应用；裁剪区域保持原预览区，不改变骨骼数据。
- `PreviewTexture.*` 共用 ImageIO 解码、PMA 转换和 GL 纹理上传；各适配层仅映射 runtime 页对象与过滤枚举。
- 2.1 的 C API 处理 Region、Mesh、SkinnedMesh；3.8 的 C++ API 处理 Region、Mesh、裁剪。2.1 仅有 Normal / Additive 混合；3.8 还支持 Multiply / Screen。
- 2.1.25 的 spine-c 没有 `SkeletonBinary`，只支持 JSON，`.skel` 会明确报错。
- 2.1 官方示例没有版本元数据，应用显示 `unknown (legacy)` 并由隔离进程校验；这种文件无法精确确认导出版本。同一上游提交中的 Raptor 示例使用 `Dev` 标记，2.1 应用也接受并原样显示，再由隔离进程校验；不把它伪装成具体版本。两个应用均不按导出版本号预先拦截；版本不一致、Dev 或版本未知时在面板提示，并继续由隔离进程尝试解析。实际解析失败仍保留原预览。
- 2.1 Atlas 页尺寸使用图片实际像素，与原始 Cocos2d-x 纹理回调一致。官方 Raptor 的 Atlas 为 1022×1022、PNG 为 1024×1024；规范化使用 1024×1024，仍检查 region 不超出图片边界。3.8 保持尺寸一致性检查。
- 2.1 读取器要求已有元数据中包含字符串 `hash`，共享准备阶段为缺省值补空字符串，避免旧解析器的空指针访问。上游源码保持原样。
- ⌘N 绑定 macOS 原生 File → New Instance 菜单，避免依赖 SDL 键盘事件中的字符映射与 repeat 状态；菜单与面板按钮共用 NSWorkspace / LaunchServices 启动路径，显式请求新实例并激活，异步启动错误回传到原实例面板。新进程使用当前应用包，通过 SDL_GetWindowSize 获取源窗口的逻辑宽高，作为启动参数传给新实例；初始加载默认示例，在源窗口右下方各偏移 50 个 SDL 屏幕坐标单位（macOS 逻辑点），先定位后显示，首帧就绪后通过 SDL_RaiseWindow 激活应用并置前，之后保持正常窗口层级。靠近屏幕边缘时限制在源屏幕可用范围，右下角无法继续偏移时向左上错开。原实例退出后仍可继续使用。
- CMake 为两个版本分别编译资源准备库并注入版本配置，分别选择示例与原始许可证；应用 ID 分别是 `local.spinepreview.v21` / `local.spinepreview.v38`。

## 验证
